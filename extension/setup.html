One-time setup

Chrome extensions can't open AirDrop on their own, so this extension uses a tiny macOS helper app. It only runs when you click Share, and all it does is open the AirDrop window.

  1. Get the project. Either clone it: 
    git clone https://github.com/TingGeorge/airdrop-in-chrome.git
cd airdrop-in-chrome
    or download the latest release from GitHub Releases and unzip it. The release includes a prebuilt helper, so you don't need Xcode.
  2. In Terminal, from that folder, install and register the helper. A git checkout needs Apple's Command Line Tools to compile it; the script tells you if they're missing. 
    ./install.sh
  3. Click Check again above. When the status turns green, you're done.

Extension ID:
If this ID isn't bknlnfilkdendhgjbkjinfammcfcpgpn (for example, you installed from the Chrome Web Store), run ./install.sh --extension-id instead.

How to share

  • Click the toolbar button (pin it from the puzzle-piece menu), or
  • press ⌥⇧A; you can change this at chrome://extensions/shortcuts,assign a keyboard shortcut at chrome://extensions/shortcuts, or
  • right-click a page or link and choose Share Page/Link via AirDrop.

The AirDrop window opens. Pick a person or device, and the link opens on the other device.
